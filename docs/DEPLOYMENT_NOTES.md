# Deployment Notes

## POC-88 — Mempool Congestion Visualizer

## 1. Overview

POC-88 consists of a Next.js frontend and a FastAPI backend.

The frontend provides the real-time dashboard and intelligence interface.

The backend provides API access to processed Bitcoin network data.

---

## 2. System Requirements

### Frontend

- Node.js 18+
- npm
- Modern web browser

### Backend

- Python 3.10+
- FastAPI
- Uvicorn
- pip

### Network

Internet connectivity is required for live Bitcoin network data.
