# POC-88 Phase 3 — Representativeness Assessment

## Dataset Character

The canonical package represents a compact operational measurement sample of Bitcoin mempool, fee, and recent-block observations.

## Coverage

- Total records: 48
- Unique observation timestamps: 11
- bitcoin_block records: 40
- fee records: 5
- mempool records: 3
- Source: mempool.space

## Temporal Coverage

The package contains 11 distinct observation timestamps within the captured collection window.

This provides limited temporal variation for descriptive and exploratory analysis but is not sufficient by itself to establish long-horizon behavior.

## Geographic Coverage

Latitude and longitude are not populated for the current canonical records. Geographic analysis is therefore outside the demonstrated coverage of this package.

## Representativeness Limitations

The canonical package should be interpreted as a captured operational sample rather than a complete representation of all Bitcoin network conditions.

The dataset is concentrated in a small set of mempool, fee, and recent-block measurements and originates from one source.

## Assessment

Representative enough for the documented analytical scope, with the above limitations explicitly retained.
